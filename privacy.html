隱私權政策

本頁說明三合院農園訂購系統及管理後台如何處理資料。

本政策自網站正式發布之日起適用。

一、適用範圍與聯絡窗口

本政策適用於三合院農園訂購系統及其管理後台。系統所有者與營運聯絡人為 Zoe，聯絡信箱為 mmsmmb88@gmail.com。訂單目前由 Zoe 一人管理。

二、處理哪些資料、用於什麼目的

  • LINE 身分識別及登入驗證相關資料：用於確認使用者身分、辨識訂單歸屬，以及提供訂單查詢與訊息服務。
  • 訂購與聯絡資料：依使用的表單與功能，包含訂購人及收件人姓名、電話、配送地址、商品、數量、金額、付款方式及狀態、出貨時段與備註，用於處理訂購、付款核對、配送、查詢與相關通知。
  • 管理與系統紀錄：依功能保存管理員登入狀態、請求識別及操作或錯誤紀錄，用於存取驗證、避免重複送單、追查異常與維護系統。

實際需要填寫的資料依當次訂購流程而定；資料不足時，相關訂購或配送流程可能無法完成。

三、Google 資料的存取與使用

Google 權限由系統營運帳戶授予後端。顧客使用 LINE 訂購，不需要授權系統存取其個人 Google 試算表或雲端硬碟。

  • Google 試算表是正式訂單的保存位置，亦保存商品與其他營運資料。
  • 程式另有 Firestore 訂單查詢快照與 Drive 備援路徑，這些是由正式資料產生的技術副本；快照欄位包含姓名、電話、地址等資料，並非只保存商品統計。系統依實際使用的功能處理這些副本。
  • Google Drive 另保存商品及橫幅圖片。供前台顯示的圖片可設定為持連結可檢視，這不表示訂單或備援公開。
  • 系統另使用 Google 服務處理排程與營運告警；初始化流程可核對營運帳戶身分。

目前 Google 授權包含完整 Drive 權限，其允許的存取範圍可能大於程式實際使用的資料範圍，不能解讀為 Google 已將存取限制在單一資料夾。營運者撤銷 Google 授權會影響後端服務，但不會自動刪除既有訂單、快照或備援。

本系統透過 Google API 取得的資料，其使用與轉移遵守 Google API Services User Data Policy，包括 Limited Use 要求。

四、儲存位置與服務提供者

依目前營運安排，訂單由 Zoe 一人管理，正式訂單保存於 Google 試算表。系統另有前述快照、備援及系統紀錄處理路徑；這些技術副本與營運者操作的正式訂單應分開理解。

LINE 提供登入與訊息服務，相關身分識別與通知內容會依功能交由 LINE 處理。訂購前台由 GitHub Pages 託管，瀏覽時瀏覽器會向託管服務請求網站檔案。

五、瀏覽器暫存與登入狀態

瀏覽器會保存訂購草稿及避免重複送單所需資訊，可能包含姓名、電話、地址及訂購內容。程式在再次讀取草稿時檢查 48 小時效期，過期才清除；這不是已成立訂單的保存期限，也不表示網站關閉後資料會在滿 48 小時時自動清除。

系統另保存完成管理員驗證所需的登入狀態。登入效期與正式訂單保存期限不同。清除瀏覽器網站資料，不會一併刪除已送至後端的訂單或備援。

六、資料保存與刪除

我們依訂購、付款核對、出貨、售後服務、系統維護及適用要求所需的範圍保存資料。不同類型的資料可能有不同保存需求；登入或暫存資料的效期，不等同於訂單與交易資料的保存期限。

對於不再有保存必要的資料，我們依資料所在位置及適用要求，安排刪除、停止使用或其他適當處理。涉及尚未完成的交易、爭議或必須保存的紀錄，保留必要部分並說明原因。

七、資料查詢、更正與刪除申請

您可透過本系統的聯絡信箱提出申請，並提供足以辨識相關訂單或帳戶的資訊。我們先確認申請人身分及資料範圍，再依實際情況與適用要求處理，並回覆處理結果或需要保留資料的原因。

申請涉及快照、備援或已匯出副本時，會一併確認可處理的範圍。移除前台顯示不代表所有副本已刪除。

八、政策更新

資料處理方式如有變更，我們會更新本頁內容及生效日期；如需另行通知，依變更內容及適用要求辦理。
